PocketASR uses a separately executed, unmodified FFmpeg LGPL shared build.
The ffmpeg directory includes the executable, all upstream shared libraries,
and upstream license files, build information and documentation.

Binary: ffmpeg-master-latest-win64-lgpl-shared.zip
Release: https://github.com/BtbN/FFmpeg-Builds/releases/tag/latest
Download: https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-lgpl-shared.zip
See BUILD-INFO.txt for the downloaded asset ID, SHA-256 and FFmpeg version.
Build recipes and dependency source references:
https://github.com/BtbN/FFmpeg-Builds
FFmpeg source: https://github.com/FFmpeg/FFmpeg
FFmpeg license information: https://ffmpeg.org/legal.html

FFmpeg is not linked into PocketASR. Users may replace the executables and
shared libraries in this directory with a compatible FFmpeg build.
